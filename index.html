Data structure for PyTorch workflows

Grow structured data flows, depth by depth.

Mangroves is a compact Python package for organising heterogeneous values into typed hierarchical layers—with dynamic attributes, filtered lookup, cross-depth grouping, and explicit tensor movement to CUDA.

Core idea

One container.
Clear data strata.

A Mangrove separates data organisation from model logic. Configure the types accepted at each depth, ingest named values once, then retrieve or update them naturally as attributes while the container tracks type and depth metadata.

T[]

Typed depths

Define allowed Python or PyTorch types per layer. Ingestion rejects unconfigured depths, disallowed types, and duplicate variable names.

m.x

Natural access

Read and update stored values through dynamic attributes while preserving the declared type contract. Filter names or values by depth and type.

GPU

Explicit device movement

Move selected tensors—or an entire depth—to CUDA when it is available, without changing how downstream code accesses the stored values.

Quick start

A useful structure
in a few lines.

Create a typed episode layer, add tensors and metadata, access values as attributes, and inspect the resulting structure. CUDA movement remains opt-in.

episode.py 
import torch
from mangroves import Mangrove

episode = Mangrove()

# Depth 1 accepts tensors and scalar rewards.
episode.config(1, [torch.Tensor, float])
episode.add_data(
    1,
    torch.Tensor,
    ["observation"],
    [torch.randn(3, 224, 224)],
)
episode.add_data(1, float, ["reward"], [0.75])

print(episode.observation.shape)
print(episode.summary())

# Optional on a CUDA-enabled machine:
# episode.tocuda(depth=1, data_type=torch.Tensor)

API map

Small surface.
Purposeful operations.

The public API stays compact enough to learn at a glance. Each method handles one part of configuration, lookup, movement, grouping, or lifecycle management.

config()

Set the accepted types for a non-zero depth.

add_data()

Ingest named values with depth and type checks.

var()

List variable names filtered by depth or type.

index()

Return filtered name-to-value mappings.

push() / shift()

Move variables between compatible depths.

tocuda()

Move matching tensor values onto a CUDA device.

inosc() / uproot()

Record and materialise cross-depth groupings.

summary()

Inspect configured, staging, and grouped data.
